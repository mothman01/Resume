mcc — C Compiler from Scratch

Personal Project · In progress · No AI-written code

C++20 · CMake · x86-64 Assembly

Writing a C compiler by hand to learn what actually happens between int main and the CPU, from the lexer down to the assembly it emits.

  1. source.c
  2. preprocess
  3. lexer
  4. parser
  5. AST
  6. codegen
  7. x86-64 .s
  8. executable
  • Built the full pipeline end to end: gcc preprocessing, a hand-written lexer, a recursive-descent parser, an AST, x86-64 assembly generation, and linking into a native executable.
  • Parser builds a unique_ptr-owned AST with nested unary expressions (-, ~) and reports clear errors for missing tokens, early end of file, and trailing junk.
  • Driver flags stop after any stage (--lex, --parse, --codegen, -S) to inspect tokens, the AST, or the generated assembly.
  • Tested against the public Writing a C Compiler test suite: all Chapter 1 tests pass, and Chapter 2 (unary operators) is in progress. My own negative tests check that malformed programs are rejected.
  • Compiles with -Wall -Wextra -Werror plus AddressSanitizer and UBSan, so memory bugs fail loudly.
